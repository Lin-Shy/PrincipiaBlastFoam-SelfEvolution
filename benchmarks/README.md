# Agent Skill Evolution Benchmarks

This directory keeps the current Chapter 4 benchmark definitions.

## Files

- `chapter4_realistic_application_benchmark.json`: canonical 12-case realistic
  application benchmark used for the Chapter 4 no-skill, abstract-skill, and
  concrete-verifier-skill e2e ablation.
- `chapter4_realistic_application_benchmark_readme.md`: role, leakage boundary,
  metrics, and current result status for the canonical benchmark.

The legacy skill-retrieval benchmark was removed after the 2026-06-06 main e2e
ablation became the thesis-facing result.
